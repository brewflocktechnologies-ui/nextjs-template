## Residual risks

- **T-13**, as above.
- **Screenshot-based recording.** Tools that capture the screen see what is displayed; DOM recorders such as rrweb see nothing (T-01).
- **Config unavailable.** If the widget config cannot be loaded, the allowlist is unknown and the frame runs with the neutral theme (ADR-007).
- **Development-only code.** The dev session adapter and publish stub exist only in development (D-12, D-13); a production build has no `/dev/session` (P1.6-AC07).

Open privacy decisions (consent wording, retention, residency) remain with product and legal (Q-006, Q-012).
