## 1. Goal

Put the governance scaffolding in place before any code changes: canonical agent instructions, ADR files, CODEOWNERS, PR template, a CI pipeline with SHA-pinned actions and no Nx Cloud, and the repository hygiene files. Everything here still runs on npm; P1.1 switches to pnpm.

## 2. Preconditions

- `STATUS.md`: P0 `Accepted`, P1.0 `Approved`.
- `npx nx run-many -t lint test build` passes on `main` as found (template baseline).

## 3. Scope

**In:** files listed in §5; CI workflow rewrite; README rewrite; Renovate config; manual GitHub settings by the product owner.
**Out:** package manager change, project renames, new projects, removing template demo code (all P1.1). Do not touch `apps/`, `packages/` except as noted in T10.

## 4. Decisions applied

D-08 (no Nx Cloud), D-09 (`SPECS/` protected by CODEOWNERS), D-18 (manual GitHub steps), D-19 (generated files committed). ## 7. Quality gates introduced

From P1.0: `policy:check` (pinned actions, ADR immutability, CODEOWNERS placeholder) and `format:check` run in CI. They become **merge-blocking at P1.1** per ARCH-001 §14.2 (branch protection requires the job from T12 onward, which may land during P1.0 itself).

## 8. Verification procedure (agent)

1. `git status --porcelain` → empty after the P1.0 commit(s).
2. `cat CLAUDE.md` → `@AGENTS.md` (+ one pointer line).
3. `grep -c "^## " AGENTS.md` → ≥ 10; grep each heading of AC02.
4. `ls docs/adr | grep -c '^ADR-0'` → `11`.
5. `npm run policy:check` → exit 0. Then temporarily edit `ci.yml` to `uses: actions/checkout@v5`, run again → non-zero with the file and line named. Revert.
6. `grep -E "start-ci-run|nx record|fix-ci|nx-cloud" .github/workflows/ci.yml` → no output.
7. `git ls-files --eol | grep -E '^i/crlf'` → no output.
8. Open the PR; CI job `lint-test-build` green; re-run → log contains `Cache restored from key: nx-Linux-…`.
9. `test -d architecture && echo STILL_THERE` → prints nothing.

## 12. Risks and notes

- `nx affected` on PRs needs `fetch-depth: 0`; forgetting it makes every PR run everything (not wrong, just slow).
- Next 16 writes `apps/web/AGENTS.md`; it is distinct from the root `AGENTS.md` and must not be confused with it (D-19).
- Branch protection cannot require the check until it has run once on `main`; merge P1.0 first, then protect.
