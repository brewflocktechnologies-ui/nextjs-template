## 1. Goal

Promote PoC-A into the production-shaped frame foundation: reusable Lit elements in `chat-widget` with `ThemeController`, `TransportController` (interface + in-memory fake), `ConsentController`; the frame uses the real `@acme/theme` guard and resolver; consent gates all persistence; i18n plumbing; a Lit Storybook with the tenant trio; budgets derived from PoC-A baselines enforced in the build; every PoC-A test becomes merge-blocking; the embedding guide is final.

## 2. Preconditions

- PoC-A code in `apps/widget` and `apps/widget-playground`; `baselines.md` filled.
- `@acme/theme/guard` entry (≤ 4 KB gz) and `resolveTheme` available; `validation/widget-fixtures` regenerated (P1.3-T12).

## 3. Scope

**In:** library elements and controllers; frame refactor onto them; consent gate and storage policy; locale/dir handling; transport fake; Storybook (web-components-vite) with Vitest addon + a11y; budgets; versioned paths check; `assert-bundle.mjs` budgets; embedding guide; ADR-007/009 updates; all PoC-A tests promoted to blocking.
**Out:** real transport (Centrifugo, later), message persistence, dashboard preview (P1.6 uses `mode=preview` which already exists from PoC-A), fonts beyond the curated five (P1.5 adds the remaining four families' woff2 files).

## 4. Decisions applied

Q-006 (consent gate), Q-012 (no message telemetry), Q-014 answered yes (D-21: domain allowlist enforced by the frame bootstrap, P1.5-T13), Q-015 per PoC-A measurement (product owner's answer in STATUS.md; default stays "at idle"). Fixed by this spec: visitor id is a `crypto.randomUUID()` stored in frame-origin `localStorage` under `acme.visitorId` **only after** consent; nothing else is persisted in Phase 1.

## 8. Verification procedure (agent)

1. `grep -rn PROVISIONAL apps/widget libs/chat-widget` → nothing.
2. `pnpm nx run-many -t test test-storybook -p @acme/widget @acme/chat-widget` → green; counts printed.
3. `pnpm nx run @acme/widget:build` → prints four `actual / budget` lines all under budget; edit `budgets.json` loader budget to `1`, rebuild → fails; revert.
4. `pnpm stack` + `pnpm nx e2e @acme/widget-playground --project=chromium` → green including `T-07`, `T-06`, `T-12`; `--grep T-05` passes.
5. `pnpm nx e2e @acme/widget-playground --project=firefox --grep "parent param"` → green locally (record version).
6. `grep -rnE "localStorage|sessionStorage|indexedDB|document\.cookie" libs/chat-widget/src apps/widget/src/frame | grep -v consent-controller` → nothing.
7. Open `http://localhost:4300/clean.html?key=wk_acme_demo&locale=ar` → frame `dir="rtl"`.

## 12. Risks and notes

- Pulling `resolveTheme` into the frame adds `design-tokens` `SCALES` to the bundle; it is small, but check against the frame budget; if it breaks the budget, emit a trimmed `scales-min.json` from tokens rather than loosening the budget.
- Storybook for web components runs stories in the real DOM; Shadow DOM internals require `shadowRoot` queries in `play()`.
- Do not implement consent UI copy beyond a placeholder; legal wording is Q-012's.
