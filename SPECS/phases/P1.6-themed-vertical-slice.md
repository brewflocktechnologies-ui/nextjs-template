## 1. Goal

Close the tenant loop end to end on the local stack: a dashboard that knows its tenant from a (development) session, renders the tenant's full theme during SSR with a nonce'd style, lets a tenant admin edit the theme with live contrast checks and a real-frame preview, and publishes to the widget's static endpoints so the embedded widget changes. Two tenants in one Node process never see each other's theme, and authenticated HTML is never cacheable.

## 2. Preconditions

- `pnpm stack` runs all three processes; playground shows the three tenants; `@acme/ui-react` exports `ThemeStyleTag`, `FilterDialog`, form components; frame supports `mode=preview` from `DASHBOARD_ORIGIN`.
- `.env.local` from `.env.local.example` (D-12/D-13 values).

## 3. Scope

**In:** request context with dev session adapter and `/dev/session` switcher; data-access stub for themes (reads/writes the widget static folder in dev through `THEME_PUBLISH_DIR`); SSR tenant theme; widget domain settings; `proxy.ts` (presence checks only); `/settings/theme` editor with preview and publish/rollback; Cache Components off; the `use cache` lint rule and `qk()` helper; `QueryClient` per request; Playwright tests for SSR theme, isolation, headers; ADR-005.
**Out:** real auth, real backend, audit log, conversation features, agent inbox, per-agent appearance overrides.

## 4. Decisions applied

D-12, D-13, Q-013 = full tenant theme (D-20), Q-014 = domain allowlist (D-21), Q-002 (editable fields). Fixed by this spec:

- **Routes**: `/` (home with brand header), `/settings/theme` (editor), `/dev/session` (dev only), `/healthz` (unauthenticated, `no-store`).
- **Session cookie** `dev-session` = `base64url(JSON{tenantId,userId,roles,locale,iat})` + `.` + `base64url(HMAC-SHA256(secret, payload))`; `getRequestContext()` in a `server-only` module verifies and returns `{ tenantId, userId, roles, locale }` or redirects to `/dev/session` (dev) / returns 401 (prod adapter placeholder throws "not implemented").
- **Data access**: `libs`-free, inside the app: `src/data/themes.ts` with `getPublishedTheme(tenantId)`, `getDraft(tenantId)`, `saveDraft(tenantId, theme)`, `publish(tenantId)`, `rollback(tenantId, revision)`; every function takes `tenantId` explicitly (lint: a custom rule flags exported functions in `src/data/**` whose first parameter is not named `tenantId`). Drafts live in a JSON file per tenant under `.local/drafts/` (gitignored). Published documents are the widget static files.
- **Publish stub** writes `themes/<tenantId>/<rev>.json` (immutable: refuses to overwrite) **then** updates `config/<widgetKey>.json` `themeRevision` (THEME-09 order). Rollback only moves the pointer.

## 8. Verification procedure (agent)

1. `pnpm nx run-many -t test lint -p @acme/admin-dashboard` → green including rule tests.
2. `pnpm stack` then `pnpm nx e2e @acme/admin-dashboard-e2e --project=chromium` → green; grep output for `T-03`, `T-04`.
3. `NODE_ENV=production pnpm nx run @acme/admin-dashboard:build && pnpm nx run @acme/admin-dashboard:start` → `curl -i http://localhost:3000/dev/session` → 404; `curl -I http://localhost:3000/healthz` → `no-store`.
4. Editor flow by script: `pnpm nx e2e @acme/admin-dashboard-e2e --grep "editor flow"` → green; then `git status --porcelain apps/widget/public` → shows the published files; `pnpm policy:check` → fails on `check-no-local-publish`; `pnpm stack:reset` → passes.
5. `pnpm nx lint @acme/admin-dashboard` after adding `import { getDraft } from '../data/themes'` to `proxy.ts` → fails; revert.

## 12. Risks and notes

- Next 16 `proxy.ts` replaces `middleware.ts`; confirm the file name and the nonce-passing pattern in `node_modules/next/dist/docs/` on the day (Next 16 agent rules warn APIs differ from training data).
- The preview iframe is cross-origin (3000 → 4400); its `parent` parameter must be `http://localhost:3000` exactly, and the frame's build-time `DASHBOARD_ORIGIN` must match — a mismatch shows up as the frame refusing `theme.preview` (`dropped.origin`). `stack:check` prints both values to make this obvious.
- Writing into another project's folder is dev-only by design (D-13); the policy script keeps it out of commits.
- If the editor needs bridge types, P1.5-T12 should already have created `libs/widget-contracts`; otherwise duplicate only the `theme.preview` payload type locally with a comment.
