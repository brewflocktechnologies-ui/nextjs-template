|            |                                     |

## 1. Goal

The dashboard renders each tenant with the artifact of its active assignment, during SSR, in the existing nonce'd style tag, with no flash and no change for migrated tenants.

## 2. Preconditions

`STATUS.md`: P2.6 `Accepted`, P2.8 `Approved`; `pnpm verify --quick` → green.

## 3. Scope

**In:** `tenant-theme.ts` reads the assigned artifact; fallback to the platform default; `system` appearance; a switch back to `resolveTheme(theme.v1)` kept until P2.10.

**Out:** widget (P2.9); previews (P2.10).

## 4. Decisions applied

ADR-005: `force-dynamic`, authenticated HTML `private, no-store`; any later cache key includes tenant, theme id, version and appearance.

## 5. Tasks

| ID       | Task                                                               | Where                                     | Done when                                       |
| -------- | ------------------------------------------------------------------ | ----------------------------------------- | ----------------------------------------------- |
| P2.8-T01 | Artifact read through the scoped function                          | `src/server/tenant-theme.ts`, `src/data/` | Unit tests pass                                 |
| P2.8-T02 | Style tag from artifact maps; fallback; `system`                   | `app/layout.tsx`, `ThemeStyleTag`         | CSP test passes                                 |
| P2.8-T03 | Tests: migrated tenants unchanged; shared theme; leakage; fallback | e2e, visual                               | Visual snapshots unchanged for migrated tenants |

## 6. Acceptance criteria

| ID        | Criterion                                                                          | Level    |
