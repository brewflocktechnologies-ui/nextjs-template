|            |                                               |
| ---------- | --------------------------------------------- |
| Status     | see `STATUS.md`                               |

| Effort     | About 1 week                                  |

## 1. Goal

The frame loads `/v1/themes/<themeId>/<version>.json` named by its config, checks it with an artifact guard and applies the allow-listed variables on the frame root, where Lit shadow roots inherit them.

## 2. Preconditions

`STATUS.md`: P2.6 `Accepted`, P2.9 `Approved`; `pnpm verify --quick` → green.

## 3. Scope

**In:** fetch by `themeId/version`; artifact guard (shape and contract allow-list); `ThemeController` allow-list from contract data; old config fields kept until P2.10.

**Out:** Tailwind in the widget (not used, ADR-017).

## 4. Decisions applied

THEME-04: the guard is hand-written, ≤ 2 KB minified, no schema library in the frame.

## 5. Tasks

| ID       | Task                                                             | Where                                      | Done when                |
| -------- | ---------------------------------------------------------------- | ------------------------------------------ | ------------------------ |
| P2.9-T01 | Artifact guard and allow-list from contract data                 | `libs/theme/src/guard.ts`, `src/contract/` | Guard tests pass; ≤ 2 KB |
| P2.9-T02 | Frame fetch by `themeId/version`, fallback to embedded defaults  | `apps/widget/src/frame/main.ts`            | Playground suite passes  |
| P2.9-T03 | Tests: computed styles inside shadow roots; two tenants; budgets | `apps/widget-playground/src/tests/`        | All pass                 |

## 6. Acceptance criteria

| ID        | Criterion                                                                         | Level    |
| --------- | --------------------------------------------------------------------------------- | -------- |
| P2.9-AC01 | Computed colours inside the chat elements' shadow roots equal the artifact values | `[auto]` |
| P2.9-AC02 | Keys outside the allow-list are rejected and reported, never applied              | `[auto]` |
| P2.9-AC03 | Widget bundle budgets hold, or a recorded exception explains the increase         | `[auto]` |
| P2.9-AC04 | An unsupported artifact renders embedded defaults                                 | `[auto]` |
