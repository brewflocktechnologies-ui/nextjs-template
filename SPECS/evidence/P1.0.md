## Deviations and findings

- **Input for P1.1:** npm 11.19 `npm ci` skipped the install scripts of `@parcel/watcher`, `@swc/core`, `nx` and `unrs-resolver` (not allow-listed), and every target still passed. These four are the starting candidates for the pnpm `allowBuilds` list in P1.1-T01; each must be justified or left out.

- **Cache key includes the commit SHA.** The spec's key (OS, lockfile hash, branch) is immutable once saved, so the cache would never update. The key now ends with `github.sha`, and `restore-keys` fall back to the newest cache for the branch, then any branch.
- **End-to-end runs Chromium only, in its own step.** The template's Playwright config defines Chromium, Firefox and WebKit, but CI installs only Chromium (spec T08). The e2e step passes `-- --project=chromium`. Firefox and WebKit move to the nightly workflow in P1.7, as planned.
- **Format check split.** Pull requests check changed files against the base; `main` checks `--all`.
- **Template files reformatted.** `nx format:write --all` changed whitespace and quotes in 15 template source and config files (`apps/web`, `packages/ui`, root Jest and ESLint configs). There are no semantic changes, and most of these files are renamed or removed in P1.1.
- **Prettier ignores** generated `next-env.d.ts` and `apps/**/AGENTS.md` (D-19), and the ARCH-001 baseline, which is not edited in place.
- **Working tree converted to LF.** The machine has global `core.autocrlf=true`, so 111 checked-out files had CRLF. The index was already LF. `.gitattributes` now forces LF on future checkouts.
- **Status badge omitted** from the README, because the product repository URL is not known yet.
- **Spec correction:** none needed.
