## Deviations and findings

1. **Targets and theme sources live in `libs/theme`, not `libs/design-tokens`.** `@byteflock/theme` already depends on `@byteflock/design-tokens`; scripts in design-tokens importing the generator would create a dependency cycle the committed project graph refuses. Theme sources are in `libs/theme/themes/<themeId>/`, artifacts in `libs/theme/generated/themes/`, targets `themes-validate|generate|compare` on `@byteflock/theme`. The platform default's sources stay in `libs/design-tokens/tokens/` and are referenced, not copied. The architecture documents name design-tokens; corrected in the P2.4 spec.
2. **`{mode}` placeholder in `semanticMap`.** The platform default puts the mode in its token paths (`semantic.light.color.primary`), while Design Token Kit uses the same path in every mode. Manifest values may contain `{mode}`, replaced by `light` or `dark`. Added to SEM-07.
3. **`RESOLVED_KEYS` kept as a literal** rather than computed from contract data, so the frame does not load the contract table and keeps literal types; a test asserts equality with the contract's required variables. P2.9 grows the allow-list.
4. **No per-gate targets** (`validate-schema`, `validate-references`, …). The generator runs G1–G7 in one pass and reports each finding with its gate; separate targets would repeat the same work for no caching gain. The spec's target list is corrected to `themes-validate`, `themes-generate`, `themes-compare`, with `build`/`build:check`.
5. **`$extends` is refused** (G2 error) rather than resolved: Design Token Kit does not document emitting it, and Style Dictionary does not support it; to revisit with real exports in P2.5.
6. **Found and fixed during implementation:** numbers in exponent form were rounded to six decimals (now expanded exactly); a file with more than 10,000 tokens was truncated silently (now a G2 error).
7. **Design Token Kit fixture is provisional**: built from its documentation (base `tokens.json` plus `tokens.dark.json` overlay, `{path}` and `$ref`). P2.5-T01 replaces it with a real export.
