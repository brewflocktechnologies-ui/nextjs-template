## Deviations

1. **Storybook set up by hand.** The chat-widget Storybook mirrors ui-react's hand-written setup instead of running the Nx generator, which in PoC-B added an unwanted test runner. `@storybook/web-components-vite` 10.6.5 matches the other Storybook packages.
2. **Frame JS budget exception.** Recorded in `budgets.json`, ADR-009 and baselines. The pull request needs a `BUDGET-EXCEPTION:` line when CI exists.
3. **Fonts through the FontFace API.** The frame CSP blocks `<style>`, so the five families are declared as a table in `src/frame/fonts.ts` and only the selected family is registered. The files are copied by `apps/widget/scripts/vendor-fonts.mjs`.
4. **Header test port.** T-12 runs the built widget under `vite preview` on port 4401, a test-only port, because the dev server holds 4400.
5. **Preview test routing.** The dashboard stand-in page is served by Playwright interception. Chrome's Local Network Access check blocks a frame on localhost from such a page, so the test proxies the widget origin through the same route; headers pass through unchanged.
6. **Fixture page location.** `wrong-domain.html` lives in `apps/widget-playground/public/` with the other fixture pages, not `src/pages/`. `embed.js` accepts `data-key` so a page can pin its key.
7. **Consent notice in the frame.** The frame shows the placeholder consent notice while consent is unknown, besides asking the host with `consent.request`. The decision is not stored; the host sends it on every page load.
8. **Config failure and the allowlist.** When the config cannot be loaded, the allowlist is unknown and the frame runs with embedded defaults, as the failure modes already specified. Recorded in ADR-007.
9. **Message list focus.** The list is the scroll region and is focusable, fixing an axe `scrollable-region-focusable` violation found by the Conversation stories.
10. **Test focus helper.** The PoC-A keyboard test now follows focus through nested shadow roots, because the composer is its own element.
