## Deviations

1. **No GitHub.** Nightly, required checks and CI timing could not run (D-22). The workflows are written and pass the pinned-actions check.
2. **Policy scripts have a local mode.** In a pull request they read the PR body; locally they read commit messages since `main` (plus `POLICY_TRAILERS`). `check-dependency-diff` accepts a sentence in a phase evidence file as the local explanation, and `tools/license-exceptions.json` as a recorded licence exception (OFL-1.1 fonts, MPL-2.0 axe).
3. **Test counting.** `vitest list` does not expand looped test names, so Vitest suites run once with the JSON reporter; Storybook tests are counted as exported stories without `!test`; Playwright uses `--list`. The check adds about 45 s to `pnpm policy:check`.
4. **Contract changes** count modifications and deletions, not the creation of a contract file (its first version).
5. **Visual snapshots** are nine, not ten: the launcher (ready, unavailable), the frame open for three tenants, the dashboard home, and FilterDialog for three tenants. They are skipped outside the container (`VISUAL=1`). The dashboard's development indicator is turned off (`devIndicators: false`) so it cannot change screenshots.
6. **Lighthouse** measures `next dev` with a development session, because the production session adapter does not exist; the numbers are indicative. Total Blocking Time stands in for INP, which a navigation run cannot measure.
7. **ARCH-001 v1.0** is not written by the agent (AGENTS.md forbids editing it); a change list is prepared for the architecture owner.
8. **CI serialises e2e** (`--parallel=1`), as `pnpm verify` does since P1.6.
