## Deviations

1. **Bridge location.** The bridge is written to `src/generated/shadcn-bridge.css`, not `src/shadcn-bridge.css`, so all generated files live under `src/generated` (D-23); the package export `./shadcn-bridge.css` points at it. The folder is excluded from Prettier.
2. **Accessibility threshold.** The a11y addon has no severity threshold, so every axe violation blocks, not only serious and critical ones. This is stricter than the spec; no story has a violation.
3. **Tenant rule specificity.** `ThemeStyleTag` writes `:root:root{…}` instead of `:root{…}`. With `:root`, the token CSS's `[data-appearance="dark"]` defaults tied on specificity and won in Storybook, so Globex showed the platform's dark primary.
4. **Bridge extras.** Beyond the colour and radius mapping, the bridge scales Tailwind's spacing by `--sem-density-factor` and text sizes by `--sem-type-scale`, maps `--font-sans` and `--shadow-md`, and makes `dark:` utilities follow `data-appearance`. Without these, density and dark mode would not reach the components.
5. **Radius cap.** `--radius` is `min(var(--sem-radius-md), 1.5rem)`. Initech's `full` radius made dialogs pill-shaped; with the cap, controls stay pills and containers get rounded corners.
6. **`'use client'`.** Added to the shadcn files that use Base UI (button, combobox, dialog, input, popover), the data table, the composite and the theme provider. The dashboard page is a Server Component and its build failed without it. `ThemeStyleTag` stays server-renderable.
7. **Dashboard config.** `transpilePackages` lists TanStack Table, which ships ESM only; `next/jest` then transforms it too.
8. **Lint helper.** `tools/eslint/tag-restrictions.mjs` takes optional extra paths and patterns, because a second `no-restricted-imports` entry would replace the tag rules.
9. **`LIB_NAME`.** Kept in the ui-react entry; the dashboard shell still lists linked libraries until P1.6.
10. **Kept story.** The PoC-B CSP story moved to `Foundations/Under strict CSP` and pins the default theme, so no tenant `<style>` appears after its CSP is installed.
