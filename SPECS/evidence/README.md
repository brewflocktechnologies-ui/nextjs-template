# Evidence files

One file per phase, created from `../templates/evidence-template.md` when the phase moves to `In progress`, named exactly after the spec: `P0.md`, `P1.0.md`, `P1.1.md`, `POC-A.md`, `P1.2.md`, `P1.3.md`, `POC-B.md`, `P1.4.md`, `P1.5.md`, `P1.6.md`, `P1.7.md`, `P1-exit.md`.

An evidence file is the proof behind a `STATUS.md` state. It is committed with the phase's final PR and never rewritten afterwards; corrections are appended with a date.
